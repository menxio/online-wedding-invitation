# RSVP security

RSVP infrastructure has not been implemented yet.

The approved default is private household invitation access using opaque credentials. Guest data must be accessed through controlled server-side operations. The future design must enforce invitation eligibility, deadlines, plus-one and child limits, canonical household responses, least-privilege database policies, rate limits, and administrator authorization.

Supabase migrations and RLS tests will be added during the RSVP backend checkpoint after business rules are reviewed.
